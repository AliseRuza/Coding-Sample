# Coding sample: Staggered DiD and child penalty (developed on Stata 18.5)

Author: Alise Ruža

## PROJECT

The goal of the project is to examine the dynamic effects of first childbirth on women's labour-market outcomes using different staggered difference-in-differences methods.

It compares TWFE and stacked diff-and-diff estimators and calculates child penalty as percentage of counterfactual earnings.

The project originated as a coding assignment for Advanced Panel Data Methods (Tilburg University, Spring 2026). I subsequently extended and refined the original implementation by:

- Improving reproducibility by adding structured project directories and better file handling.
- Adding data validation checks to verify the consistency and structure of the datasets used in the analysis.
- Improving the construction of aggregation weights using the number of distinct treated individuals in each sub-event.
- Implementing an individual-level cluster bootstrap with 500 replications to obtain inference for the child penalty measure.

## HOW TO RUN

1. Make sure the `dataset.dta` is in `/data` folder.
2. Open Stata in this folder (or double-click `panel_assignment.do`) and run it.
   Outputs (graphs, tables, log) are saved to `/output`.

Required SSC packages (with the version used):
reghdfe 6.12.3, ftools 2.50.0, estout (esttab 2.1.1), palettes (colorpalette 1.2.8), coefplot 1.8.6, bacondecomp 1.0.5

## DATA

**DATA:** The analysis uses a simulated individual-level panel dataset. The dataset is designed to replicate the main features of maternal labour-market outcomes around first childbirth, as observed in German administrative data.

**TREATMENT:** Treatment is absorbing as individuals are untreated before their first childbirth and remain treated thereafter. Treatment timing varies across individuals according to their age at first childbirth, generating a staggered adoption setting.

**UNIT OF OBSERVATION:** individual-age pair.

**VARIABLES:**

- `pid`: Individual identifier.
- `age`: Individual's age at observation.
- `agefirst`: Age at first childbirth.
- `treated`: Treatment status.
- `reltime`: Time relative to first childbirth.
- `labearnings`: Annual labour earnings from employment.

## OUTPUT FILES

`/output` folder contains the graphs, estimation tables and log files that are generated by running the `analysis.do` file.
